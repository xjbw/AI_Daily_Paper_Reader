## 摘要
多模态推荐通过利用异构模态信息来缓解数据稀疏并提高推荐准确性，已引起广泛关注。现有方法试图用多模态特征替代ID嵌入，并取得了初步的有希望的结果。然而，这些方法仍存在以下两个局限性：（1）重构的ID表示仍然相对静态，未能充分利用多模态语义；（2）图学习过程在挖掘潜在的长尾语义关系方面不足，且易受流行度偏差影响。为解决这些问题，我们提出了一种名为模态感知身份构建与反事实结构学习的无ID多模态推荐新方法（MAIL）。具体而言，我们设计了一个模态感知身份构建模块，该模块通过多模态语义动态调制位置编码，以构建内容感知的无ID身份表示。然后，我们提出了反事实结构学习范式，通过流行度惩罚挖掘低曝光语义邻居，并缓解流行度偏差。在五个公开的Amazon数据集上进行了大量实验。实验结果表明，与基线模型相比，MAIL在Recall@10和NDCG@10上分别平均提升了7.81%和12.81%。我们的代码可在https://github.com/HubuKG/MAIL获取。

## Abstract
Multimodal recommendation has attracted extensive attention by leveraging heterogeneous modality information to alleviate data sparsity and improve recommendation accuracy. Existing methods have attempted to replace ID embeddings with multimodal features and have achieved promising preliminary results. However, these methods still exhibit the following two limitations: (1) the reconstructed ID representations remain relatively static and fail to fully exploit multimodal semantics; and (2) the graph learning process is insufficient in mining latent long-tail semantic relations and is easily affected by popularity bias. To address these issues, we propose a novel method named Modality-Aware Identity Construction and Counterfactual Structure Learning for ID-free Multimodal Recommendation (MAIL). Specifically, we design a modality-aware identity construction module that dynamically modulates positional encodings with multimodal semantics to construct content-aware ID-free identity representations. Then, we propose a counterfactual structure learning paradigm that mines low-exposure semantic neighbors via popularity penalization and alleviates popularity bias. Extensive experiments are conducted on five public Amazon datasets. Experimental results show that MAIL achieves average improvements of 7.81% in Recall@10 and 12.81% in NDCG@10 compared with the baseline models. Our code is available at https://github.com/HubuKG/MAIL.

## 2. 论文提出的方法论

提出的模型**MAIL**（Modality‑Aware Identity Construction and Counterfactual Structure Learning）包含三个主要模块，整体流程见图2。

### 2.1 模态感知身份构建（MAIC）
- **模态投影**：将用户的文本和视觉原始特征（用户特征由其交互物品的特征平均得到）通过全连接层和激活函数投影到统一隐空间，得到$z^t_x, z^v_x$。
- **模态感知门动态调制位置编码**：
  - 从文本和视觉表示分别生成门控信号$\gamma^t_x, \gamma^v_x$（通过Sigmoid函数）。
  - 将两个门控按权重$\alpha_p$融合为$g_x$，再对基础位置编码$p_x$进行逐元素调制：$p'_x = g_x \odot p_x$。
- **身份表示融合**：将调制后的位置编码分别注入文本和视觉表示，再进行模态融合，得到初始内容感知的无ID身份表示：
  $$e^{(0)}_x = \alpha_m(z^t_x + p'_x) + (1-\alpha_m)(z^v_x + p'_x)$$

### 2.2 反事实结构学习（CSL）
- **反事实邻居增强（CNA）**：
  - 基于物品融合语义表示$h_i$计算余弦相似度$s_{ij}$。
  - 引入**流行度惩罚**：$s^{cf}_{ij} = \frac{s_{ij}}{(\text{pop}(j)+\epsilon)^{\lambda_{cf}}}$，其中$\text{pop}(j)=\log(1+n_j)$，$n_j$为物品交互数，$\lambda_{cf}$控制惩罚强度。
  - 依据该惩罚后的分数选择Top‑$K_{cf}$个低曝光但语义相关的邻居，构建反事实物品‑物品图$R^{cf}_I$，并与基础KNN图$R^{base}_I$按权重$\eta$融合，再与用户‑用户图及交互矩阵组合成增强的异构图$A_{aug}$。
- **结构对比增强（SCE）**：
  - **跨层对齐损失**$\mathcal{L}_A$：使传播前的语义身份表示与传播一层的结构表示在高维空间中对齐，保留反事实结构信息。
  - **去耦判别损失**$\mathcal{L}_D$：强制初始身份表示靠近原始多模态语义，远离过度融合的公共结构表示，提高语义–结构的可区分性。
  - 结构对比增强总损失$\mathcal{L}_{SCE} = \mathcal{L}_A + \mathcal{L}_D$。

### 2.3 推荐与训练目标
- 使用LightGCN在增强图上进行$L$层传播，得到最终用户表示$e_u$和物品表示$e_i$。
- 预测分数为内积$\hat{r}_{u,i}=e_u^\top e_i$。
- 采用**余弦相似度 softmax 排名损失**$\mathcal{L}_{rec}$替代传统BPR损失。
- 保留跨模态InfoNCE损失$\mathcal{L}_m$维持模态一致性。
- 最终联合损失：
  $$\mathcal{L} = \mathcal{L}_{rec} + \lambda_m \mathcal{L}_m + \lambda_S \mathcal{L}_{SCE}$$

### 2.4 训练算法
- 先离线计算增强图$A_{aug}$，再在每个批次中执行MAIC、图传播和损失计算。
- 复杂度分析：训练复杂度为$O(L|E_{aug}|d + |B|^2 d)$，与主流GNN多模态推荐方法处于同一量级。
