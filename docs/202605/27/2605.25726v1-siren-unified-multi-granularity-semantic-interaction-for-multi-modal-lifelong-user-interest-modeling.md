## 摘要
工业推荐系统日益利用终身用户行为历史和丰富的多模态内容来捕捉不断变化的用户偏好。然而，由于多模态空间与协同过滤空间之间存在固有的不对齐问题，将多模态特征有效融入终身兴趣建模仍面临挑战。现有范式通常依赖于分别建模多模态序列和行为序列，并通过后期融合来缓解模态差异，这导致多模态表示粒度较粗且整合有限。在本文中，我们提出SIREN，一个面向多模态终身用户兴趣建模的统一多粒度语义交互框架。在通用搜索单元阶段，我们引入两种可选的检索策略：基于多模态相似度的软检索以提升检索有效性，以及基于语义ID的硬检索以实现高效的工业级服务。在精确搜索单元阶段，我们通过粗粒度的相似度桶和细粒度的前缀编码语义ID显式地融入目标感知相关性，从而在目标条件Transformer架构中实现与协同ID特征的统一交互。在离线数据集上的大量实验表明，SIREN达到了业界领先的GAUC指标。在线A/B测试进一步显示在多个生产场景中GMV均有一致提升，其中微信朋友圈提升2.28%，微信公众号提升3.87%，微信视频号提升1.61%。自2025年7月起，SIREN已在腾讯广告平台全面上线，服务全量流量。

## Abstract
Industrial recommender systems increasingly leverage lifelong user behavior histories and rich multi-modal content to capture evolving user preferences. However, effectively integrating multi-modal features into lifelong interest modeling remains challenging due to the inherent misalignment between multi-modal and collaborative spaces. Existing paradigms typically rely on separate modeling of multi-modal sequence and behavior sequence, and late fusion to alleviate the modality gap, which results in coarse-grained multi-modal representation and limited integration. In this paper, we propose SIREN, a unified multi-granularity semantic interaction framework for multi-modal lifelong user interest modeling. In the General Search Unit stage, we introduce two alternative retrieval strategies: multi-modal similarity-based soft retrieval for retrieval effectiveness, and Semantic ID (SemID)-based hard retrieval for efficient industrial serving. For the Exact Search Unit stage, we explicitly incorporate target-aware relevance via coarse similarity buckets and fine-grained prefix-encoded SemIDs, enabling unified interaction with collaborative ID features within the target-conditioned transformer architecture. Extensive experiments on the offline dataset demonstrate that SIREN achieves a state-of-the-art GAUC. Online A/B tests further demonstrate consistent GMV gains across multiple production scenarios, including +2.28% in Weixin Moments, +3.87% in Weixin Official Accounts, and +1.61% in Weixin Channels. From July 2025, SIREN has been fully launched for full-traffic serving in Tencent's advertising platform.

## 1. 论文的核心问题与整体含义
工业推荐系统（尤其是广告、信息流、电商场景）越来越依赖**终身用户行为序列**与**多模态内容**来捕捉用户兴趣的动态演化。然而，有效融合多模态特征到终身兴趣建模中面临一个核心挑战：**预训练的多模态嵌入与协同过滤空间存在根本性的不对齐**。现有主流范式（如MUSE等）采用“分而治之”的策略：将多模态序列与行为序列分别建模，在序列聚合后才进行晚期融合。这种解耦范式导致两个主要问题：
- 多模态信号不能在序列建模过程中与协同信号充分交互，沦为辅助分支，限制了推荐表征的判别力；
- 目标–历史行为的相似度仅提供粗粒度的相关性视角，忽略同一相似度桶内因语义差异导致的协同反馈异质性（如图2所示），难以捕捉细粒度的兴趣差异。

**核心含义**：本文提出SIREN，一个**统一多粒度语义交互框架**，旨在从检索（GSU）到精确排序（ESU）的完整两阶段范式中，将多模态信号与协同ID特征在**物品级别进行早期融合**，从而让多模态语义与协同信号在同一建模空间内紧密交互，实现更准确、更细粒度的用户兴趣理解。

## 2. 方法论：核心思想、关键技术细节与算法流程
SIREN遵循工业界广泛使用的**GSU–ESU两阶段范式**，并在两个阶段内分别引入多粒度语义交互机制。

### 2.1 多模态特征构建
为将连续的多模态嵌入 $e_i^{\text{mm}}$ 转化为推荐系统友好的离散形式，并注入目标感知的细粒度信号：
- **语义ID (SemID)**：利用RQ-VAE将 $e_i^{\text{mm}}$ 量化为层级代码 $(c_i^{(1)}, c_i^{(2)}, \dots, c_i^{(M)})$。采用**前缀编码**：构建前缀 token 序列 $\mathcal{P}_i$，通过共享嵌入表得到语义表示 $e_i^{\text{sem}} = \text{Concat}(\{E_{\text{prefix}}[p] \mid p \in \mathcal{P}_i\})$。
- **目标感知相似度桶 (Similarity Bucket)**：计算行为 $b_i$ 与目标项 $v_t$ 的余弦相似度 $s_{i,t}$，将连续值离散化到 $B$ 个桶中，获得桶索引 $q_{i,t}$，再映射为可学习嵌入 $e_{i,t}^{\text{Sim}}$。

### 2.2 通用搜索单元（GSU）的多模态检索
SIREN 提供两种检索策略，灵活平衡检索质量与工业部署效率：
- **软检索 (Similarity-based Soft Retrieval)**：基于 $e^{\text{mm}}$ 的余弦相似度，从全量历史中直接检索 Top-K 最相似行为。检索质量高，但在线计算和存储开销大。
- **硬检索 (SemID-based Hard Retrieval)**：利用目标项 SemID 的顶层代码 $c_t^{(1)}$ 查询倒排索引，召回共享相同顶层代码的历史行为。将全量复杂度 $O(|B|·d)$ 降为近似常量时间，大幅降低部署成本（在线成本降低超90%），性能仍具竞争力。

### 2.3 精确搜索单元（ESU）的统一目标条件序列建模
在检索到的短序列上，SIREN 进行**物品级早期融合**：
1. **统一物品表示**：对每个行为 $b_i$ 构造 $\mathbf{h}_i = \text{Concat}(e_i^{\text{id}}, e_i^{\text{sem}})$，目标项同样得 $\mathbf{h}_t$。相似度桶嵌入作为注意力调制的附加条件。
2. **目标感知注意力**：多头目标注意力计算行为的重要性权重 $\alpha_i$，其输入为 $[\mathbf{h}_i \oplus e_{i,t}^{\text{Sim}}]$ 与 $[\mathbf{h}_t \oplus e_t^{\text{Sim}}]$，从而同时感知协同特征、语义内容和目标相关性。
3. **目标条件交互**：对聚合后的用户兴趣 $ \mathbf{u}_t = \sum \alpha_i \mathbf{h}_i $，进一步与目标项进行逐元素相乘 $\tilde{\mathbf{u}}_t = \mathbf{u}_t \odot \mathbf{h}_t$，显式捕捉细粒度兼容模式。
4. 最终预测 $\hat{y}_t = \sigma(g([\tilde{\mathbf{u}}_t, \mathbf{h}_t, \mathbf{u}, \mathbf{c}]))$。

**核心公式脉络**：
- SemID 生成：$ \text{SemID}_i = (c_i^{(1)}, \dots, c_i^{(M)}) $
- 前缀表示：$ e_i^{\text{sem}} = \text{Concat}(\{E[p]\}) $
- 相似度：$ s_{i,t} = (e_i^{\text{mm}})^\top e_t^{\text{mm}} / (\|e_i^{\text{mm}}\|\| e_t^{\text{mm}}\|) $，离散化为 $q_{i,t}$
- 统一表示：$ \mathbf{h}_i = [e_i^{\text{id}}; e_i^{\text{sem}}] $
- 目标感知聚合：$ \alpha_i = \text{Attn}(\mathbf{h}_i \oplus e_{i,t}^{\text{Sim}}, \mathbf{h}_t \oplus e_t^{\text{Sim}}) $，$ \mathbf{u}_t = \sum \alpha_i \mathbf{h}_i $
- 目标交互：$ \tilde{\mathbf{u}}_t = \mathbf{u}_t \odot \mathbf{h}_t $

## 7. 优点（方法或实验设计亮点）
- **系统级创新**：从GSU到ESU完整注入多粒度语义，提供检索效率和效果可配置的工业级方案。
- **物品级早期融合**：将多模态特征直接融入序列内各物品表示，突破了传统的“分支+晚期融合”局限，实现了协同与语义信息的深度交互。
- **多粒度语义设计**：语义ID（细粒度内容语义）与相似度桶（目标感知关联）的组合，显式区分“这个行为是什么”与“它和目标有多相关”，有效缓解了协同异质性问题。
- **实验扎实**：丰富离线消融与表示分析，结合大规模在线A/B测试，且有冷启动细分分析，充分证明了方法的实用价值。
- **部署友好**：提供软/硬检索的清晰效率–性能折衷，硬检索方案已实现大规模上线。

## 8. 不足与局限
- **实验泛化性**：离线实验仅基于**一个公共数据集**（Taobao-MM），未在其他公开多模态序列推荐数据集（如亚马逊、MovieLens多模态版）上验证，其跨场景通用性需更多证据。
- **算力信息缺失**：未报告训练所需计算资源，影响对方法落地成本的全面评估（尤其是软检索端到端训练）。
- **对预训练嵌入质量的依赖**：SemID硬检索和相似度桶的性能高度依赖高质量、与协同信号对齐的多模态嵌入；若上游多模态编码器欠佳，SIREN的优势可能被稀释。
- **硬检索的覆盖风险**：SemID硬检索只匹配顶级语义代码，可能丢失部分语义相似但代码不同的跨类行为，召回率存在上限。
- **在线提升幅度解读**：离线GAUC绝对提升较小（+0.0011），其增益虽在工业界被认为有意义，但读者可能对消融实验中的提升量级存在疑虑，需结合在线GMV提升综合判断。
- **方法复杂度**：SIREN引入了SemID构建、前缀编码、多桶离散化等模块，增加了系统复杂度和超参数调优负担。
