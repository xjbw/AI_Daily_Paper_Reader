## 摘要
许多化工系统受随操作状态切换的机制支配，因此数据驱动地发现依赖于状态的支配方程对于预测建模、优化和控制至关重要。我们提出符号决策树用于数据驱动地发现依赖于状态的支配方程。该方法同时学习可解释的划分条件以分割输入域，以及描述每个状态的局部支配方程。为提高可处理性，划分条件和支配方程均使用基函数参数化，形成一个混合整数优化学习问题。我们使用所提出的方法学习混合动力学模型以及聚合物熔体零剪切粘度的本构方程。符号决策树识别出物理上可解释的状态和局部支配方程，同时相对于学习单一全局模型或使用现有决策树模型的方法，提高了预测精度。该框架为在化工系统中发现依赖于状态的模型提供了一条可解释且可推广的途径。

## Abstract
Many chemical engineering systems are governed by mechanisms that switch across operating regimes, making the data-driven discovery of regime-dependent governing equations essential for predictive modeling, optimization, and control. We propose symbolic decision trees for the data-driven discovery of regime-dependent governing equations. The method simultaneously learns interpretable splitting conditions to partition the input domain and local governing equations that describe each regime. To improve tractability, both the splitting conditions and governing equations are parametrized using basis functions, resulting in a mixed-integer optimization learning problem. We use the proposed approach to learn hybrid dynamical models and a constitutive equation for the zero-shear viscosity of polymer melts. Symbolic decision trees identify physically interpretable regimes and local governing equations while improving predictive accuracy relative to approaches that learn a single global model or use existing decision tree models. This framework provides an interpretable and generalizable route for discovering regime-dependent models in chemical engineering systems.

### 2. 论文提出的方法论

- **核心模型：符号决策树**
  - 将依赖于状态的支配方程表示为一棵决策树：内部节点为**非线性划分条件** $g_n(x) < b_n$ 或 $g_n(x) \ge b_n$，叶子节点为**局部预测方程** $f_n(x)$。
  - 目标函数综合了**预测误差** $L_{acc}$、**树结构复杂度** $L_c$ 以及**方程系数的幅值** $L_m$，通过权重参数 $\lambda_c, \lambda_m$ 调节。

- **关键技术细节**
  - **基函数参数化**：划分函数 $g_n(x)$ 和叶子预测方程 $f_n(x)$ 均用基函数 $\phi_k(x)$ 的线性组合表示，即 $g_n(x)=\sum_{k} a_{nk} \phi_k(x)$，$f_n(x)=\sum_{k} c_{nk} \phi_k(x)$。
  - **混合整数优化 (MILP) 形式化**：引入二元变量表示节点是否为分支、特征是否被选用、数据点分配到哪个节点等，将所有结构性约束（如数据点必须满足祖先节点的划分条件）和预测计算线性化，最终形成一个可求解的 MILP 问题。
  - **求解**：使用现成的 MILP 求解器（Gurobi）直接寻找在给定基函数集下的全局最优树结构。

### 6. 论文的主要结论与发现

- 所提符号决策树能够**精确恢复各状态内的正确函数形式**（如正确识别出斜率 1 和 3.4）。
- **划分条件边界**的恢复可能因训练数据有限而存在较小偏差（例如，案例1中阈值由 2.5 变为 2.54，案例3中由 $\log_{10}M=4.49$ 变为 4.24），增加数据可改善。
- 在预测精度上显著优于单一稀疏回归模型和普通决策树，尤其是在状态边界附近，普通决策树和稀疏回归会产生系统性较大误差。
- 对数据噪声具有一定的鲁棒性：尽管方程系数误差随噪声增大，但功能形式始终被正确识别。

### 7. 优点

- **同时学习划分与局部模型**：将两步过程统一为单一优化问题，划分直接服务于预测精度。
- **可解释性强**：输出的是明确的解析表达式和清晰的逻辑条件，符合科学发现和工程应用需求。
- **形式化为 MILP**：在给定基函数库下能够获得全局最优解，避免了启发式符号回归方法的局部最优问题。
- **复杂度可控**：可显式约束划分条件和局部方程使用的基函数数量，抑制过拟合。

### 8. 不足与局限

- **可扩展性受限**：随着数据量、树深度、基函数库增大，MILP 问题规模急剧膨胀，求解耗时将不可接受，论文未涉及大规模问题的加速策略验证。
- **依赖于基函数库的选择**：方法不能凭空创造新函数形式，若真实方程包含库外函数则无法精确发现，本质上是一种“稀疏线性组合发现”，而非完全自由的符号回归。
- **划分边界存在退化现象**：由于数据稀疏，可能存在多组划分达到相同预测精度，导致恢复的边界与真实物理边界有偏移，丧失了部分物理意义上的可解释性。
- **实验验证相对基础**：所有案例均为低维仿真系统，未在真实实验数据或更复杂的高维化工流程上验证。
- **输出模型可能不连续**：决策树的分裂硬边界导致模型在状态边界处天然不连续（除非后处理或数据恰好使左右叶节点输出连续），这与许多物理系统的连续性假设不符。
