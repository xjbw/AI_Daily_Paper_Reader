## 摘要
生成式序列模型在推荐系统中展现出强大性能，将其应用于搜索排序则更具挑战性。搜索行为本质上是查询驱动的，每次查询切换都会导致用户交互历史出现剧烈的主题转变。现有的生成方法将查询和物品展平成单一的 token 序列，未能区分查询边界，导致模型将不同的查询意图混淆为一个预测目标，产生噪声监督。我们提出查询条件式生成搜索 (QGS)。QGS 将每次交互编码为一个 (查询, 物品) 对 token，并以查询条件下一物品为目标进行训练。预测目标从带噪声的边际分布 P(item_{t+1}|context_{<=t}) 转变为干净的条件分布 P(item_{t+1}|context_{<=t}, query_{t+1})。这直接消除了查询切换引起的语义不连续性。使用标准注意力编码长交互历史的计算复杂度为二次，在严格的在线延迟预算下不可行。我们引入了线性 HSTU 编码器，用因果线性递归替代全注意力，每层复杂度从 O(L^2) 降至 O(L)，且排序质量无损失。传统搜索排序依赖于手工设计的特征，如文本匹配分数、统计信号和行为特征。我们提出 HFG-Attention，在生成框架中保留这些特征。它将异构特征组织成语义组，并通过专用注意力块进行融合，连接了稀疏工程信号与稠密序列表示。QGS 已部署在中国主流商业搜索引擎 Quark 搜索的排序模块中。线上 A/B 测试显示统计显著增益：相比生产环境深度学习基线，点击率提升 0.62%，点击搜索比提升 0.38%，页面浏览时长提升 3.55%。

## Abstract
Generative sequence models have shown strong results in recommendation. Applying them to search ranking is more challenging. Search behavior is inherently query-driven. Each query switch introduces a sharp topic shift in the user's interaction history. Existing generative methods flatten queries and items into a single token sequence. They do not distinguish query boundaries. This causes the model to mix different query intents into one prediction target, resulting in noisy supervision.   We present Query-Conditioned Generative Search (QGS). QGS encodes each interaction as a (query, item) pair token. It trains with a query-conditioned next-item objective. The prediction target changes from a noisy marginal P(item_{t+1}|context_{<=t}) to a clean conditional P(item_{t+1}|context_{<=t}, query_{t+1}). This directly removes the semantic discontinuity caused by query switches.   Encoding long interaction histories with standard attention has quadratic cost. This is impractical under strict online latency budgets. We introduce a Linear HSTU encoder. It replaces full attention with causal linear recurrence. Per-layer complexity drops from O(L^2) to O(L) with no loss in ranking quality.   Traditional search ranking depends on hand-crafted features like text-matching scores, statistical signals, and behavioral features. We propose HFG-Attention to preserve them in the generative framework. It organizes heterogeneous features into semantic groups and fuses them through a dedicated attention block. This bridges sparse engineered signals with dense sequential representations.   QGS is deployed in the ranking module of Quark Search, a major commercial search engine in China. Online A/B tests show statistically significant gains: +0.62% CTR, +0.38% Click-Search Ratio, and +3.55% PV Duration over the production deep learning baseline.

### 1. 论文的核心问题与整体含义

**研究动机与背景**

- 生成式序列模型（如 HSTU、SASRec 等）在推荐系统中取得了显著成功，其核心是将用户行为序列建模为自回归的“下一物品预测”任务。
- 将这类方法直接迁移到**搜索排序**场景时，面临一个根本性的语义断裂：搜索行为是**查询驱动**的，用户每切换一次查询，整个候选集和交互意图都会发生剧烈跳变（例如“量子计算”→“古罗马史”→“热带冰沙”）。
- 现有的生成式搜索方法将查询与物品展平为单一的物品序列（Item-Only），**不区分查询边界**，导致模型被迫从上下文直接预测下一个物品，即学习一个带噪声的边际分布 $P(\text{item}_{t+1} \mid \text{context}_{\le t})$。由于序列中缺乏查询的因果解释，相邻物品之间的语义跃迁变成了无法解释的随机噪声，严重混淆了训练信号。
- 因此，论文的核心问题是：**如何设计一种能够显式建模查询-物品条件依赖的生成式搜索框架，从源头上消除序列中的语义不连续性，使预测目标从含噪的边际分布转变为干净的条件分布。**

### 2. 提出的方法论

QGS 由四个关键组件构成，共同实现查询条件式的生成搜索。

**核心思想与关键技术细节**

- **查询-物品对 Token 构建 (Query-Item Pair Token Construction)**
  - 将每一条用户搜索交互 $(q_t, d_t)$ 编码为一个独立的“对 token”，而非仅用一个物品向量。
  - 具体实现：将查询文本与文档文本拼接后输入预训练 BERT，提取两个语义向量：`[CLS]` 输出作为**物品级语义嵌入** $\mathbf{e}^{\text{cls}}_t$；第一个 `[SEP]` 输出作为**查询级语义嵌入** $\mathbf{e}^{\text{sep}}_t$。
  - 同时融入该交互的数值/类别上下文特征（如点击率、展示位置、时效性等），拼接后构成对 token $\mathbf{x}_t = [\mathbf{f}_t \parallel \mathbf{e}^{\text{cls}}_t]$，再经线性投影与位置编码得到编码器输入 $\mathbf{h}^{(0)}_t$。
  - 查询语义嵌入 $\mathbf{e}^{\text{sep}}_{t+1}$ 被保留，专供后续的查询条件预测使用。

- **查询条件式下一物品预测目标 (Query-Conditioned Next-Item Prediction)**
  - 训练时，在时间步 $t$，将编码器输出 $\mathbf{h}^{(N)}_t$ 与**下一个查询**的语义嵌入 $\mathbf{e}^{\text{sep}}_{t+1}$ 拼接，经预测头得到 $\mathbf{z}_t$。
  - 正样本为 $t+1$ 步的物品表示 $\mathbf{v}_{t+1} = W_{\text{tgt}}\,\mathbf{x}_{t+1}$，负样本采自同 batch 内的其他序列。
  - 使用 InfoNCE 对比损失进行优化，公式为：
    $$
    \mathcal{L}_{\text{InfoNCE}} = -\frac{1}{|\mathcal{V}|} \sum_{t\in\mathcal{V}} \log \frac{\exp(s^{(b,b)}_t)}{\sum_{c=1}^{B} \exp(s^{(b,c)}_t)}
    $$
    $$s^{(b,c)}_t = \frac{\bar{\mathbf{z}}^{(b)}_t \cdot \bar{\mathbf{v}}^{(c)}_{t+1}}{\tau}$$
  - 该设计将预测目标从 $P(\text{item}_{t+1} \mid \text{context}_{\le t})$ 转变为 $P(\text{item}_{t+1} \mid \text{context}_{\le t}, \text{query}_{t+1})$，直接将查询切换的因果信息注入训练信号中。

- **线性 HSTU 编码器 (Linear HSTU Encoder)**
  - 动机：处理长达 1000 的交互历史，标准 Transformer 或 HSTU 的 $O(L^2)$ 注意力成本在严格的线上延迟预算下不可行。
  - 方案：将 HSTU 的点积聚合注意力改造为**因果线性递归**形式，保留其无 softmax 设计和 U-gating 机制。
  - 具体结构：输入经 RMSNorm 后，计算四个投影：
    $$\mathbf{Q} = \text{SiLU}(\mathbf{H}W^Q),\; \mathbf{K} = \text{SiLU}(\mathbf{H}W^K),\; \mathbf{V} = \text{SiLU}(\mathbf{H}W^V),\; \mathbf{U} = \text{SiLU}(\mathbf{H}W^U)$$
    通过逐元素乘积与因果累积和实现线性递归：
    $$\mathbf{S}_t = \mathbf{K}_t \odot \mathbf{V}_t,\quad \mathbf{C}_t = \sum_{\tau=1}^{t} \gamma^{t-\tau} \mathbf{S}_\tau = \gamma \mathbf{C}_{t-1} + \mathbf{S}_t$$
    输出为 $\mathbf{O}_t = \mathbf{Q}_t \odot \mathbf{C}_t \odot \mathbf{U}_t$。
  - 每层复杂度降至 $O(L\cdot d_h)$，且在序列长度 1000 时推理速度提升 37%，排序质量无损失。

- **异构特征分组注意力 (HFG-Attention)**
  - 动机：候选物品的交叉特征（如查询-文档匹配分）不能作为序列输入，但却至关重要；且这些特征异构（高维稀疏 + 低维稠密），直接与稠密序列表示拼接效果差。
  - 方案：先将异构稀疏特征按语义归类为若干组（如位置特征组、统计特征组），每组投影到一个统一的低维空间 $d_e$；再附加一个全局上下文 token（由共享 DNN 生成），构成一个短序列。
  - 对该短序列施加一层标准 HSTU 注意力（带 FFN）进行跨组交互，最后用掩码平均池化得到融合后的稀疏特征表示 $\mathbf{h}_{\text{sparse}}$，并与序列表示 $\mathbf{h}_{\text{seq}}$、候选文档嵌入等拼接，送入多任务预测塔。

### 7. 优点

- **问题定义精准**：敏锐地抓住了搜索行为与推荐行为在序列建模上的本质差异，并直接针对查询切换带来的“语义跳跃噪声”设计解决方案，而非简单复用推荐模型。
- **方法论创新层次分明**：
  - 数据层面：查询-物品对 token，将每个交互的因果对结构注入序列表示。
  - 目标层面：查询条件式预测，将边际分布变为条件分布，训练信号去噪。
