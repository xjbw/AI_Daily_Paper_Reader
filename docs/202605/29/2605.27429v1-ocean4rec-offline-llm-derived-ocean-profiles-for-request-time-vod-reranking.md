## 摘要
工业视频点播（VOD）推荐系统需要更丰富的内容理解，但将LLM作为重排序器的设计在每次请求时都会重复构造提示、生成令牌、调用模型、解析输出以及处理回退。在高容量延迟敏感的服务中，这些请求时操作使得吞吐量规划、尾延迟控制、容量隔离和可预测运维变得复杂。本文提出Ocean4Rec，一种仅在离线阶段使用LLM从内容元数据中物化物品OCEAN剖面的重排序层。物品被映射到开放性、尽责性、外向性、宜人性和神经质得分，而用户剖面则通过最近点击和深度链接物品在同一五维空间中的时间衰减聚合构建。在请求时，Ocean4Rec连接预先计算的物品剖面、用户剖面、基础推荐器得分和目录新鲜度，然后在不调用LLM的情况下执行数值重排序。在匿名三星智能电视VOD日志上，相同候选集的前1000名时间保留离线评估表明，Ocean4Rec相对于更强的非OCEAN基础+新鲜度排序，对NCF生成器将NDCG@20提升了7.6%，对LightGCN生成器提升了61.5%。HR@20对NCF无明确结论，对LightGCN提升了67.3%，反映了稀疏精确项重放标签以及新鲜度作为工业基线的作用。该结果应被解读为一种有界辅助内容品味特征的离线重放证据，该特征保留了无请求时LLM服务路径的可部署性优势。

## Abstract
Industrial video-on-demand (VOD) recommenders need richer content understanding, but LLM-as-reranker designs repeat prompt construction, token generation, model invocation, output parsing, and fallback handling for each request. In high-volume latency-sensitive services, these request-time operations complicate throughput planning, tail-latency control, capacity isolation, and predictable operation. This paper presents Ocean4Rec, a reranking layer that uses an LLM only offline to materialize item OCEAN profiles from content metadata. Items are mapped into Openness, Conscientiousness, Extraversion, Agreeableness, and Neuroticism scores, while user profiles are built by time-decayed aggregation of recently clicked and deep-linked items in the same five-dimensional space. At request time, Ocean4Rec joins precomputed item profiles, user profiles, base recommender scores, and catalog recency, then performs numeric reranking without an LLM call. On anonymized Samsung Smart TV VOD logs, same-candidate Top1000 temporal-holdout offline evaluations show that Ocean4Rec improves NDCG@20 over a stronger non-OCEAN Base+Recency ordering by 7.6% for an NCF generator and 61.5% for a LightGCN generator. HR@20 is inconclusive for NCF and improves by 67.3% for LightGCN, reflecting sparse exact-item replay labels and the strength of recency as an industrial baseline. The result should be read as offline replay evidence for a bounded auxiliary content-taste feature that preserves the deployability advantage of a request-time-LLM-free serving path.

*   **整体含义**：本文旨在探索一种新的范式，即将LLM的昂贵推理能力**完全移至离线阶段**，用于预先提取物品的丰富内容特征，而在线请求时则采用纯数值计算进行重排序，从而在利用LLM强大语言理解能力的同时，保持在线服务路径的轻量级、高效率和可预测性。

### 2. 论文提出的方法论

Ocean4Rec的核心思想是解耦LLM推理与在线服务，并将其应用于物品和用户表示的构建。

*   **核心思想**：利用心理学中“大五人格”模型（OCEAN）框架作为内容理解的标准，让LLM仅根据物品元数据生成五维人格剖面，然后在线下和线上分别构建物品和用户的同一空间表示，最后在请求时进行轻量级匹配。
*   **关键技术细节**：
    1.  **离线物品OCEAN剖面生成**：
        *   对于一个VOD物品，将其标题、情节、描述等**元数据**输入到LLM（Google Gemini 2.5 Pro）中。
        *   LLM输出一个JSON记录，包含物品ID和五个维度的整数得分：开放性 ($Openness$)、尽责性 ($Conscientiousness$)、外向性 ($Extraversion$)、宜人性 ($Agreeableness$)、神经质 ($Neuroticism$)。
        *   输出还包括置信度和简短理由，并对无效输出进行重试或回退处理。
    2.  **在线用户OCEAN口味剖面构建**：
        *   基于用户 $u$ 最近对已剖面物品的交互行为（点击、深度链接）来构建剖面。
        *   采用指数时间衰减机制对交互行为进行加权，公式为 $w_{time}(a) = 0.5^{a/h}$，其中 $a$ 为交互发生距今的天数， $h$ 为半衰期（文中设为90天）。
        *   用户剖面 $z_u$ 是其历史上交互物品OCEAN得分的加权平均： $z_u = \frac{\sum_{(i,t,e) \in H_u} w_{time}(a_t) q_i}{\sum_{(i,t,e) \in H_u} w_{time}(a_t)}$，其中 $q_i$ 为物品 $i$ 的OCEAN向量。
    3.  **请求时数值重排序算法流程**：
        *   对于每个候选物品 $i$，其最终得分 $S(u,i)$ 由三部分线性组合而成： $S(u,i) = \alpha B(u,i) + \beta P(u,i) + \gamma R(i)$。
            *   $B(u,i)$：基础推荐器得分，进行最小-最大归一化。
            *   $P(u,i)$：OCEAN兼容性得分，计算用户向量 $z_u$ 和物品向量 $q_i$ 之间的**皮尔逊相关系数** $\rho$，并通过 $P(u,i) = \frac{\text{clip}(\rho(z_u, q_i), -1, 1) + 1}{2}$ 转换到 $[0, 1]$ 区间。
            *   $R(i)$：目录新鲜度得分，基于物品发行日期计算，公式为 $R(i) = 0.5^{\frac{\text{ContentReleaseAgeDays}_i}{365}}$。
        *   $\alpha, \beta, \gamma$ 为固定权重系数。该过程完全不涉及LLM调用，仅需特征查找和数学运算。

### 3. 实验设计

    *   **辅助数据集**：使用了亚马逊图书（Amazon-Books）和Yelp Restaurants的公开子集进行补充诊断。

*   **实验范围的局限性**：
