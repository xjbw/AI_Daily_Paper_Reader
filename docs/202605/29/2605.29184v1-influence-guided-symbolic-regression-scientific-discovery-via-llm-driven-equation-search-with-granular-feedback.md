## 摘要
大型语言模型（LLMs）为科学发现提供了有前景的途径，但其在符号回归中的应用常受限于低效的搜索策略和粗糙的反馈信号。现有方法通常使用标量指标（如全局均方误差）来引导LLM，这无法识别所提出方程中哪些成分驱动性能或导致错误。我们提出影响力引导的符号回归（IGSR），该方法将方程发现构建为一个迭代的两步过程，结合多样化的项生成与严格的选择：LLM为线性模型生成候选基函数 $\psi_j(\mathbf{x})$，然后使用细粒度的影响力得分 $\Delta_j$ 进行评估。这些得分量化了每一项对泛化精度的边际贡献，从而实现了影响力引导的剪枝过程，系统地优化模型结构。将该机制整合到蒙特卡洛树搜索（MCTS）中，能够在组合搜索空间中导航，平衡对新函数形式的探索与对高影响力成分的利用。我们在多种基准测试上展示了IGSR的有效性，包括LLM-SRBench、药理学PKPD模型、流行病学模拟和真实世界基因组数据。值得注意的是，我们通过一个使用高维生物数据集的案例研究验证了该框架真正发现的能力，其中IGSR识别出DNA甲基化与RNA聚合酶II暂停之间的新颖关系；这一假设随后通过湿实验得到了支持。

## Abstract
Large Language Models (LLMs) offer a promising avenue for scientific discovery, yet their application to symbolic regression is often constrained by inefficient search strategies and coarse feedback signals. Current methods typically guide LLMs using scalar metrics (e.g., global Mean Squared Error), which fail to identify which components of a proposed equation are driving performance or causing error. We introduce \textit{Influence-Guided Symbolic Regression} (IGSR), a method that frames equation discovery as an iterative two-step process combining diverse term generation with rigorous selection: an LLM generates candidate basis functions $ψ_j(\mathbf{x})$ for a linear model, which are then evaluated using granular influence scores $Δ_j$. These scores quantify each term's marginal contribution to generalization accuracy, enabling an influence-guided pruning process that systematically refines the model structure. Integrating this mechanism into a Monte Carlo Tree Search (MCTS) enables navigating the combinatorial search space while balancing exploration of novel functional forms with exploitation of high-influence components. We demonstrate IGSR's effectiveness on a diverse suite of benchmarks, including LLM-SRBench, pharmacological PKPD models, an epidemiological simulation, and real-world genomic data. Notably, we validate the framework's capacity for genuine discovery in a case study using a high-dimensional biological dataset, in which IGSR identified a novel relationship between DNA methylation and RNA Polymerase II pausing; a hypothesis that was subsequently supported via wet-lab experimentation.

## 论文核心问题与整体含义

现有工作已经尝试利用大型语言模型（LLMs）进行符号回归式科学发现，但主流方法通常仅依赖全局标量损失（如整体均方误差）作为反馈信号。这种粗糙的反馈无法解释**方程的哪一项真正有效、哪一项引入了噪声**，导致发现过程退化为低效的试错循环。论文《影响力引导的符号回归》（IGSR）正是为解决该问题而提出：**将“项生成”与“项选择”解耦，并通过细粒度的逐项影响力得分进行结构择优**，从而把 LLM 的创造性与严格的统计选择结合起来，实现更可靠、更高效的方程发现。

## 方法设计：影响力引导的提出–剪枝循环与蒙特卡洛树搜索

IGSR 的核心是将方程发现形式化为一个“提出–剪枝”的迭代过程，并将其嵌入蒙特卡洛树搜索（MCTS）以在组合空间中平衡探索与利用。方法包含以下几个关键技术步骤：

- **目标模型形式**：寻找稀疏可解释模型  
  $$f(\mathbf{x}) = \sum_{j} w_j \psi_j(\mathbf{x})$$  
  其中 $\psi_j(\mathbf{x})$ 为 LLM 提出的非线性基函数，$w_j$ 为通过线性模型（例如普通最小二乘）拟合的权重。

- **逐项影响力得分 $\Delta_j$（核心反馈信号）**：
  对完整模型 $f(\mathbf{x})$ 在验证集上的均方误差 $\mathrm{MSE}_{\mathrm{full}}$，定义项 $j$ 的影响力得分为移除该项（$w_j \leftarrow 0$）而保持其他系数不变时验证集 MSE 的变化：
  $$\Delta_j = \mathrm{MSE}_{-j} - \mathrm{MSE}_{\mathrm{full}}$$
  $\Delta_j$ 越大表示该项对泛化精度的边际贡献越大，该信号直接用于后续剪枝决策。

- **提出–剪枝循环（每次 MCTS 节点扩展的基本操作）**：
  1. **项生成阶段**：LLM“提议”代理根据任务描述、当前项集合、历史决策（哪些项被保留/丢弃及其对 MSE 的影响）生成新的候选基函数 $\psi_j(\mathbf{x})$。
  2. **评估与影响力计算**：将新旧候选合并，在训练集上拟合线性模型得到权重 $w$，然后在验证集上计算每一项的 $\Delta_j$。
  3. **项剪枝阶段**：默认采用确定性剪枝——按 $\Delta_j$（多输出时取跨目标的最大值）排序，仅保留前 $K$ 项（如 $K=6$）；同时支持“IGSR‑Agent”变体，由第二 LLM 代理在 $\Delta_j$ 基础上结合语义推理进行名词性剪枝。被保留的项及其决策记录作为历史反馈指导下一轮生成。

- **搜索策略**：将上述循环嵌入 MCTS。每个节点代表一个方程状态（当前项集合及其权重），从父节点通过多次随机 LLM 调用生成多个子节点（默认 5 个）。使用 UCT 准则平衡探索与利用，节点奖励直接取当前方程的负验证 MSE（启发式 MCTS）。搜索总扩展预算默认 30 次。

该方法将 LLM 的生成先验与统计影响力分析严格分离，既防止了 LLM 幻觉对统计显著项的误删，又利用细粒度反馈实现了高效的结构导航。

- **基准实验**：6 个数据集，25 个随机种子，每个种子独立数据划分与模型训练。
- **LLM‑SRBench**：128 个问题，每问题 5 种子，覆盖四个科学领域，并提供域级分项结果。
- **消融研究**：分别剥离 MCTS、影响力反馈、剪枝方式（确定性 vs. LLM），揭示各组件的贡献。
- **扩展验证**：不同 LLM 骨干（9 种，含开源模型）的敏感性分析、无关特征干扰实验、合成模型测试、独立生物重复泛化分析、MCTS 走子深度、提示简化、项生成宽度等超参数消融。
- **统计学严谨**：使用 95% 置信区间、再现性检验（paired t‑test、ANOVA）、跨种子方程结构稳定性分析（Jaccard 相似度、热图）。
- **现实世界验证**：湿实验验证了 IGSR 生成的甲基化‑暂停假说，并在多个随机种子和独立生物重复中检验了假说的稳定性。

总体而言，实验覆盖面广、重复次数充分、对比基线合理，结果具有较强的客观性与公平性。

## 主要结论与发现

1. **IGSR 在可解释模型中性能领先**：在 6 个基准数据集上，IGSR 在 5/6 个数据集上取得了白盒方法中最低的测试 MSE，且整体优于所有传统符号回归和其他 LLM 方程发现基线。
2. **细粒度影响力反馈是关键**：消融实验表明，移除逐项影响力得分或 MCTS 均导致性能显著下降；影响力反馈带来更快收敛和更低最终误差。
3. **高效的高维扩展能力**：在 263 维的 RNA 聚合酶数据集上，IGSR 运行时间呈亚线性增长，未出现传统方法（如 OpenFE、AutoFeat）因组合爆炸而超时或内存溢出。
4. **LLM‑SRBench 上兼顾预测与结构恢复**：IGSR 在 In‑Distribution 和 Out‑of‑Distribution 测试集上均获最佳平均排名，同时 Term Recall 和 Symbolic Accuracy 亦优于对比方法，体现了真正的科学发现而非记忆。
5. **真实科学发现能力**：IGSR 成功识别出 DNA 甲基化抑制转录暂停的新假设，并通过 5‑azacytidine 去甲基化实验显著观察到暂停增强，完成了从硅基假设到湿实验验证的完整闭环。

## 优点

- **创新的反馈机制**：用逐项影响力得分代替全局标量反馈，实现了细粒度信用分配，显著提升搜索效率。
- **模块化且可扩展的框架**：将 LLM 生成与统计选择解耦，既允许确定性剪枝（抗幻觉、高效）也支持 LLM 语义剪枝（可注入领域知识）；可轻松切换 MCTS 与线性迭代等多种搜索模式。
- **出色的可解释性**：最终输出显式线性方程 $\sum w_j \psi_j(\mathbf{x})$，每项贡献明确，便于领域专家审查和假设生成。
- **严格的真实性验证**：不仅评估预测精度，还通过湿实验证实了一种全新生物机制，极大强化了方法的科学价值。
- **多维度鲁棒性验证**：在不同的 LLM 骨干、噪声特征干扰、合成函数乃至独立生物重复下，IGSR 均保持一致优势。

## 不足与局限

- **受限于 LLM 先验**：若所需函数形式未出现在 LLM 预训练分布中，系统难以自发提出；对嵌套非线性或微分方程系统可能弱于端到端可微分方法。
- **模型假设为线性组合**：基础形式 $f(\mathbf{x}) = \sum w_j \psi_j(\mathbf{x})$ 限制了表达式复杂度，尽管引入了参数局部优化（IGSR‑TLO），但对深度嵌套结构的表达依然有限。
- **计算成本依赖 LLM API**：多次 LLM 调用带来 token 成本和延迟，尽管文中已展示在固定 token 预算下 IGSR 的效率优势，但对于超大规模搜索仍可能昂贵。
- **剪枝决策的潜在盲点**：确定性剪枝完全依赖 $\Delta_j$，在极端共线或纯交互情境中虽经专项测试表现良好，但未广泛探索更复杂的系数可辨识性问题。
- **部分基准对比的局限性**：某些黑盒基线（如 Transformer）并非针对动力学方程开发，可能未调优到最佳；材料科学领域符号恢复率较低，暗示结构近似可能牺牲了精确功能形式。
