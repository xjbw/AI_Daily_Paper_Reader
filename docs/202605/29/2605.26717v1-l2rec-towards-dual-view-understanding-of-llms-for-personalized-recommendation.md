## 摘要
为个性化推荐而适配大语言模型（LLMs）需要将其通用能力与用户特定偏好对齐，同时有效利用行为与语义信号。现有方法通常在输入层面（例如将行为嵌入注入词元空间）或输出层面（例如对分离编码器进行对比对齐）集成这些信号，但面临分布差异或缺乏端到端任务监督的问题。在本文中，我们提出 L2Rec，它在 LLM 的参数层面统一了行为与语义理解。我们的核心见解是：同一组 Transformer 参数可以作为两种视角的共享媒介：通过双视角个性化专家混合（DPMoE）机制应用视角特定的个性化低秩扰动，L2Rec 使得单个 LLM 主干能为每个用户产生互补的行为与语义适应，且表征层面的错位最小。自适应跨视角融合模块进一步将双视角输出整合为统一的用户偏好。在四个数据集上的实验表明 L2Rec 始终优于最先进的基线，且在大规模工业平台上的在线 A/B 测试验证了关键互动指标的显著提升。

## Abstract
Adapting large language models (LLMs) for personalized recommendation requires aligning their general-purpose capabilities with user-specific preferences while effectively leveraging both behavioral and semantic signals. Existing approaches typically integrate these signals at either the input level (e.g., injecting behavioral embeddings into the token space) or the output level (e.g., contrastive alignment of separate encoders), suffering from distribution gaps or lack of end-to-end task supervision. In this work, we introduce L2Rec, which unifies behavioral and semantic understanding at the parameter level of LLMs. Our key insight is that the same set of Transformer parameters can serve as a shared medium for both views: by applying view-specific, personalized low-rank perturbations via a Dual-view Personalized Mixture-of-Experts (DPMoE) mechanism, L2Rec enables a single LLM backbone to produce complementary behavioral and semantic adaptations for each user with minimal representation-level misalignment. An adaptive cross-view fusion module further integrates the dual-view outputs into a unified user preference. Experiments on four datasets show that L2Rec consistently outperforms state-of-the-art baselines, and online A/B testing on a large-scale industrial platform validates significant improvements in key engagement metrics.

### 2. 论文提出的方法论

论文提出了 **L2Rec** 框架，其核心思想、关键技术与流程如下：

*   **核心思想**：对冻结的大语言模型主干网络（参数为 $W$），分别应用视角特定的低秩调整 $\Delta W^S$ 和 $\Delta W^B$，产生适配后的参数 $\widetilde{W}^S = W + \Delta W^S$ 和 $\widetilde{W}^B = W + \Delta W^B$。由于两个调整都作用于共享的、基于大语言模型预训练知识的参数空间，行为和语义视角共享一个共同的表征邻域，从而显著降低了跨视角对齐的难度。

*   **关键技术细节**：
    1.  **双视角输入构建**：
        *   **语义视图**：将用户交互序列中所有物品的文本内容拼接成一个长的词元序列 $E^S_u$，以捕获细粒度的文本偏好。
        *   **行为视图**：将每个物品压缩为一个单一向量，生成一个物品级序列 $E^B_u$，以建模序列交互动态。
    2.  **双视角个性化专家混合 (DPMoE)**：
        *   **目的**：以一种用户自适应且参数高效的方式生成调整量 $\Delta W^S$ 和 $\Delta W^B$。
        *   **专家池划分**：将 LoRA 专家池划分为**共享专家**（$E_{sh}$，始终激活以提供跨视角通用知识）和**视角特定专家**（$E^v$，如 $E^S$ 和 $E^B$，稀疏激活以捕捉用户和视角依赖的专长）。
        *   **个性化路由**：关键创新在于，视角特定专家的激活由**三信号路由器**决定，综合考虑了上下文（$x_j$）、用户表征（$u$）和两者交互（$[u; x_j]$），使得相同的输入能为不同用户激活不同专家。
        *   **调整量计算**：对于 Transformer 某层的参数矩阵 $W_j$，其调整量 $\Delta W_j$ 由共享专家和经路由权重 $g_{j,i}$ 加权后的视角特定专家的低秩矩阵乘积之和构成。
    3.  **自适应跨视角融合 (ACF)**：通过残差投影和动态门控机制，将 DPMoE 输出的两个视图的用户表征 $h^S_u$ 和 $h^B_u$ 融合为最终的用户偏好表征 $h^F_u$。
    4.  **训练目标**：整体框架采用三个互补的损失函数进行端到端训练：
        *   **推荐对比损失** ($\mathcal{L}_{Rec}$)：标准的用户-物品对比学习损失。
        *   **双向偏好对比损失** ($\mathcal{L}_{BPC}$)：对齐同一用户的行为和语义视图表征，同时推开不同用户，以保持跨视图偏好一致性。
        *   **负载均衡损失** ($\mathcal{L}_{LB}$)：防止专家路由崩溃。
        *   最终损失为 $\mathcal{L} = \mathcal{L}_{Rec} + \gamma\mathcal{L}_{BPC} + \beta\mathcal{L}_{LB}$。训练期间，大语言模型主干保持冻结，仅更新 DPMoE 和 ACF 的参数。
