## 摘要
电商图像搜索常以裁剪后的图像作为查询，而每个候选者由完整商品图像和结构化文本表示。这种图像到多模态的检索设置呈现出两种不对称性：模态差异——视觉查询必须匹配图像-文本条目，以及粒度差异——裁剪后的查询需与包含背景上下文和可能干扰物的完整图像进行比较。基于检测的流程通过显式定位处理粒度差异，但会带来额外成本和误差传播，而CLIP风格的编码器避免了检测，却易受背景或无关物品影响。为解决这些局限，我们提出TIGER-FG，一种面向图像到多模态电商检索的文本引导隐式细粒度定位框架。TIGER-FG利用商品文本作为语义引导，在无需目标检测的情况下生成聚焦目标的商品表示用于检索。我们进一步引入双重蒸馏目标，保留目标区域的空间一致性和查询-商品相似度结构，得到更稳定且具有判别力的多模态表示。此外，我们构建了ECom-RF-IMMR，一个现实的基准套件，包含一个千万级对的训练集和两个覆盖标准与杂乱商品布局的评估基准。在两个评估基准上，TIGER-FG较最强基线分别提升了6.1和34.4个百分点的R@1，且仅需85.7M查询端参数和256维嵌入。在公开电商基准上的结果进一步展示了其在噪声和一对多检索场景下的泛化能力。代码和数据将开源。

## Abstract
E-commerce image search often takes a cropped image as the query, while each candidate is represented by full item images and structured text. This image-to-multimodal retrieval setting presents two asymmetries: a modality disparity -- a visual query must match image--text items, and a granularity disparity -- a cropped query must be compared with full images containing background context and possible distractors. Detection-based pipelines handle the granularity disparity through explicit localization but incur extra cost and error propagation, whereas CLIP-style encoders avoid detection, but are vulnerable to backgrounds or irrelevant items. To address these limitations, we propose TIGER-FG, a text-guided implicit fine-grained grounding framework for image-to-multimodal e-commerce retrieval. TIGER-FG uses item text as semantic guidance to produce target-focused item representations without object detection for retrieval. We further introduce dual distillation objectives that preserve target-region spatial consistency and query--item similarity structure, yielding more stable and discriminative multimodal representations. In addition, we construct ECom-RF-IMMR, a realistic benchmark suite with a 10M-pair training set and two evaluation benchmarks covering standard and cluttered item layouts. TIGER-FG improves Recall@1 over the strongest baseline by 6.1 and 34.4 percentage points on the two evaluation benchmarks, respectively, with only 85.7M query-side parameters and 256-dim embeddings. Results on public e-commerce benchmarks further demonstrate its generalization to noisy and one-to-many retrieval scenarios. Code and data will be released.

    *   **粒度差异**：查询聚焦于商品局部，而候选图片是包含背景、多件商品或其它干扰物的完整场景图。

*   **本研究动机**：旨在提出一种无需显式检测，即可在完整的多模态候选商品中实现细粒度定位的新型检索框架，从而同时解决模态和粒度两大不对称问题。

### 2. 论文提出的方法论

TIGER-FG框架的核心思想是**利用商品的结构化文本作为语义引导**，在不进行目标检测的情况下，从完整的商品图片和文本中直接生成**目标聚焦的商品表征**。

*   **框架概述**：采用非对称的双编码器架构，查询编码器处理裁剪区域，商品编码器处理完整的图文对。
*   **文本引导的商品表征**：
    *   **视觉与文本Token化**：使用DINOv3 ViT编码商品图片得到视觉Token $V$，使用BERT编码商品文本得到文本Token $T$。
    *   **文本引导的交叉注意力**：维护一组可学习的查询Token $Q$，它们先与文本Token $T'$ 进行交叉注意力交互，生成文本条件化的查询 $Q'$；然后 $Q'$ 再与视觉Token $V'$ 进行交叉注意力交互，得到文本引导的视觉Token $\tilde{V}$。通过一个可学习的加权聚合层，最终输出富含文本指导语义的特征 $f^m$。
        $$f^m = \sum_{k=1}^{N_q} \pi_k \tilde{V}_k, \quad \pi = \text{softmax}(\text{MLP}_\pi(\tilde{V}))$$
    *   **互补视觉分支**：为防止模型忽略文本未明示的视觉线索，引入一个并行的视觉池化分支。该分支以文本引导特征 $f^m$ 和视觉类别Token $c'$ 为锚点，计算所有视觉Patch Token的相似度得分并融合，通过池化得到纯视觉特征 $f^a$。最终的商品表征为 $f^i = f^m + \text{MLP}(f^a)$。
*   **双重蒸馏目标**：
    *   **空间关系蒸馏**：促使学生模型的Patch级特征与冻结的DINOv3教师模型保持一致，特别是在目标框区域内的特征空间结构，从而增强模型的局部定位能力。损失函数为它们的空间自相似性矩阵的KL散度：$L_{SRD} = \frac{1}{B} \sum_{j=1}^B D_{KL}\left( \text{softmax}(A_j^t) \parallel \text{softmax}(A_j^s) \right)$。
    *   **相似度分布蒸馏**：使用一个冻结的、预训练好的图像到图像检索模型作为教师，蒸馏其查询与批量内所有候选商品之间的相似度分布。这旨在保留教师模型的全局视觉相似性结构，提升检索的判别力。损失函数为教师与学生预测的相似度分布的KL散度：$L_{SDD} = \frac{1}{B} \sum_{j=1}^B D_{KL}\left( p_j^t \parallel p_j^s \right)$。
*   **辅助优化目标**：
    *   **区域-文本嵌入空间对齐**：在融合前，将裁剪的目标区域与其结构化文本进行CLIP式的对比学习，预先建立跨模态的局部区域对齐。
    *   **目标锚定的融合-区域对齐**：使用裁剪区域的视觉特征作为锚点，通过对比学习拉近融合后的商品表征与它的距离，同时利用类别不同的错误文本构造硬负例，迫使表征聚焦于正确的目标商品。

*   TIGER-FG在电商图像到多模态检索任务上显著优于现有方法，尤其是在候选商品图片中存在大量干扰物的复杂场景下优势巨大。
