## 摘要
基于遗传编程的符号回归（GPSR）可能存在过拟合和结构膨胀问题，尤其是在存在噪声时。在本文中，我们评估了描述长度（DL）和分数贝叶斯因子（FBF）准则，将其作为有原则的、数据高效的方法，替代启发式方法来选择泛化良好的紧凑表达式。我们使用基于费雪信息的参数编码实现DL，并在多个数据集上将其与AIC和BIC进行比较，包括含噪合成基准和真实回归问题。我们研究了三种搜索/选择策略：(i) 以精度和程序长度为优化目标的多目标搜索，随后通过DL/FBF选择；(ii) 直接以DL作为优化目标的多目标搜索；(iii) 以DL/FBF作为适应度的单目标优化。在多个数据集上，我们发现与AIC/BIC基线相比，DL/FBF后选择提高了测试性能，并且BIC结合与DL/FBF相同的函数复杂度惩罚项产生了类似的结果。相反，在单目标GPSR中直接使用DL/FBF作为适应度函数，经常导致过早收敛到过于简单的模型。我们总结了在遗传编程工作流中使用DL/FBF作为稳健模型选择工具的实践指导。

## Abstract
Symbolic regression with genetic programming (GPSR) may suffer from overfitting and structural bloat, especially when noise is present. In this paper we evaluate description length (DL) and fractional Bayes factor (FBF) criteria as principled, data-efficient alternatives to heuristics for selecting compact expressions that generalise well. We implement DL using a Fisher-information-based parameter encoding and compare it to AIC and BIC across multiple datasets, including noisy synthetic benchmarks and real-world regression problems. We study three search/selection strategies: (i) multi-objective search for accuracy and program length followed by DL/FBF selection; (ii) multi-objective search using DL directly as an objective; and (iii) single-objective optimisation with DL/FBF as the fitness. Across datasets we find that DL/FBF post-selection improves test performance compared to AIC/BIC baseline and that BIC in combination with the same function complexity penalty from DL/FBF produces similar results. In contrast, using DL/FBF directly as a fitness function in single-objective GPSR frequently induces premature convergence to overly simple models. We conclude with practical guidance for using DL/FBF as robust model-selection tools in genetic programming workflows.

本文的核心动机是：**引入描述长度（Description Length, DL）与分数贝叶斯因子（Fractional Bayes Factor, FBF）作为原则性的、数据高效的模型选择准则**，替代传统的AIC/BIC或启发式惩罚项，以在GPSR流程中自动且稳定地发现紧凑、泛化性能良好的表达式模型。研究进一步明确了DL/FBF在不同搜索策略（多目标后选择、多目标直接目标、单目标适应度）中的作用差异，揭示其作为“后选择工具”的显著优势，以及作为“搜索驱动力”时的潜在风险。

### 2. 论文提出的方法论
核心思想是**利用最小描述长度原则与分数贝叶斯因子，为GPSR中的表达式模型提供量化的、结构感知的复杂度评价**，并将该准则融入多目标或单目标遗传编程流程中。

- **描述长度（DL）的改进实现**
  - 在Bartlett等人工作的基础上，DL同时考虑**数据编码长度**、**函数结构复杂度**和**参数复杂度**。
  - 函数复杂度使用项 `$k \log n + \sum_{c_i} \log c_i$` 编码，其中 $k$ 为表达式树节点数，$n$ 为不同符号数量，$c_i$ 为常数。
  - 参数复杂度通过**完整的费雪信息矩阵(FIM)** 刻换，而非仅利用对角线。利用FIM的**奇异值分解（SVD）** 将参数旋转到近似独立的方向，并使用特征值 $S_{ii}$ 作为参数离散化网格的尺度。这相对于轴平行的格子缩短了强相关参数的编码长度，同时抑制了退化（sloppy）方向的贡献，提高GPSR场景下的稳定性与合理性。
  - 最终DL定义为：  
    $$ \text{DL} = -\log\mathcal{L}(\hat{\theta}, \hat{\sigma}_{\text{err}}^2) + k\log n + \sum_{c_i} \log c_i + \frac{1}{2}\sum_{i=1}^{p} \max\big(0, \log S_{ii} - \log 3 + \log|\hat{\theta}^{\text{rot}}_i|\big). $$
- **分数贝叶斯因子（FBF）**  
  FBF利用部分数据作为校准样本生成参数先验，其余数据用于模型比较，由此避免复杂参数先验设定，且计算上比DL更廉价（不需FIM）。文中采用FBF形式为：
  $$ \text{FBF} = -(1-b)\log\mathcal{L}(\hat{\theta}, \hat{\sigma}_{\text{err}}^2) + \text{func comp} + \frac{p}{2}\big(\log(2\pi e^{1-\log 3}) - \log b\big), $$
  其中 $b = m^{-1/2}$（$m$ 为样本量）。

- **算法变体**  
  1. **MO-Length**：多目标GP（NSGA-II）同步优化负对数似然（NLL）和程序长度；生成Pareto前沿后，由DL、FBF、AIC、BIC等准则从中选取单个模型。  
  2. **MO-DL**：多目标GP优化NLL与DL模型复杂度惩罚项（即函数复杂度+参数复杂度）。  
  3. **SO**：单目标GP，直接以AIC、BIC、BIC$_{\text{SR}}$（BIC+函数复杂度）、DL或FBF作为适应度单目标最小化。

- **参数优化**：所有候选表达式在评估时均通过Levenberg-Marquardt优化参数（最大似然/最小二乘），并进行剖面噪声方差估计。

### 6. 论文的主要结论与发现
- **DL、FBF与BIC$_{\text{SR}}$（BIC加函数复杂度惩罚）在后选择场景下效果相近且优于AIC和标准BIC**，它们在多目标MO-Length中倾向于选择紧凑、训练误差接近噪声水平、泛化性能更好的表达式，有效抑制过拟合和膨胀。
- **直接用DL/FBF作为单目标SO的适应度会导致过早收敛到过度简化的模型**，测试性能显著劣于多目标后选择。原因是强烈的结构惩罚快速消除多样性，使搜索陷入局部短解。

- DL能根据数据特征（噪声水平、样本量）**自动调节所选表达式的复杂度**：噪声低、样本多时选择较长的模型，反之选择较短模型，无需手工调整正则化系数。
- 对Nikuradse等物理数据集，DL/FBF选出的模型在外推行为上明显优于AIC/BIC选择，避免极端过拟合。

- **广泛的实证验证**：覆盖大量且多样的数据集与设定，附有详细的收敛曲线、预测图、箱线图和多数据集统计比较。

- **计算效率考量**：尽管DL通常只对Pareto前沿计算，但涉及全FIM和SVD，高维参数时计算开销增加，未深入分析大规模场景下的性能瓶颈。

- **统计方法仅依赖BBT**：BBT用于整体排序，但未提供每个数据集上的显著性测试或置信区间分解，对个别数据集上的反常表现（如Tower数据集中AIC反而更好）缺乏深入统计解释。
