## 摘要
现实电商平台中的长尾推荐由于严重的数据不平衡仍然具有挑战性。现有方法往往难以将基于内容的多模态特征与协同信号相结合。其中许多方法还忽略了头部ID与尾部ID之间知识迁移的一个重要不对称性：来自尾部ID的噪声信号可能会损害头部ID的表示学习。本文提出了AKT-Rec，一个利用大语言模型生成语义ID进行长尾推荐中非对称知识迁移的框架。AKT-Rec使用多模态大语言模型（MLLMs）进行有监督微调，以对齐物品和用户的内容表示与协同信息，生成语义表示。然后，它通过残差量化变分自编码器（RQ-VAE）将这些表示离散化为语义ID，从而得到相似实体的语义聚类。AKT-Rec有两个主要组成部分：（1）聚类引导的自适应嵌入，它将每个ID表示分解为捕捉共享语义的聚类级嵌入和个体嵌入。通过非对称对比目标和活动感知的门控机制，该模块引导知识从头部ID迁移到尾部ID。（2）层次化特征聚合，构建并行特征视图并自适应融合，以优化对不同活动水平样本的预测。在大规模工业数据集上的广泛实验以及在天猫平台上的在线A/B测试证明了AKT-Rec的有效性。AKT-Rec在离线AUC上提升0.35%，在GAUC上提升1.53%，优于多个竞争基线。在线A/B测试中，AKT-Rec实现了2.76%的点击率提升和3.47%的成交额提升，验证了其在真实生产环境中的实用性。

## Abstract
Long-tail recommendation in real-world e-commerce platforms remains challenging due to severe data imbalance. Existing methods often struggle to combine content-based multimodal features with collaborative signals. Many of these methods also ignore an important asymmetry in knowledge transfer between head and tail IDs: noisy signals from tail IDs can hurt representation learning for head IDs. This paper presents AKT-Rec, a framework for Asymmetric Knowledge Transfer in long-tail Recommendation that uses LLM-generated semantic IDs. AKT-Rec uses Multimodal LLMs (MLLMs) with supervised fine-tuning to align content representations with collaborative information for both items and users, producing semantic representations. It then discretizes these representations into semantic IDs with a Residual-Quantized VAE (RQ-VAE), which yields semantic clusters of similar entities. AKT-Rec has two main components: (1) Cluster-Guided Adaptive Embedding, which decomposes each ID representation into a cluster-level embedding that captures shared semantics and an individual embedding. Through an asymmetric contrastive objective and an activity-aware gating mechanism, this module directs knowledge transfer from head to tail IDs. (2) Hierarchical Feature Aggregation, which builds parallel feature views and adaptively fuses them to optimize predictions for samples with varying activity levels. Extensive experiments on a large-scale industrial dataset and online A/B testing on the Alibaba Tmall platform demonstrate the effectiveness of AKT-Rec. AKT-Rec improves offline performance by 0.35% in AUC and 1.53% in GAUC, outperforming several competitive baselines. In online A/B testing, AKT-Rec achieves a 2.76% increase in CTR and a 3.47% increase in GMV, validating its utility in real-world production environments.

论文针对真实电商平台中的长尾推荐问题展开研究。核心挑战在于用户行为与物品交互呈现严重的长尾分布：少数热门物品与活跃用户占据绝大多数曝光，而大量冷门物品和低活用户缺乏足够数据，导致传统模型难以学习到可靠的表示。现有方法存在两个关键不足：
- 基于图神经网络或样本增强的方法受限于数据稀疏性、噪声引入或分布扭曲；
- 多数工作只关注尾部对象的表征增强，**忽视了知识迁移中的不对称性**：来自尾部ID的噪声信号反而可能损害头部ID（热门物品/高活用户）的表示学习，而头部拥有的丰富交互信号本可以更好地支持尾部。

为此，论文提出 AKT-Rec 框架，其核心含义是：**通过大语言模型生成的语义ID，构建一种从头部到尾部的非对称知识迁移机制，使头部知识单向、安全地流向尾部，同时保护头部表示不受尾部噪声污染，进而整体提升长尾推荐效果。**

## 2. 论文提出的方法论
AKT-Rec 包含两个主要阶段：**语义聚类生成**和**基于语义聚类的特征融合**。

### 2.1 语义聚类生成
- **多模态表示提取**：使用预训练的 MLLM（如 GME-Qwen2-VL-7B）对物品的多模态内容（图片、文本、统计特征）编码；通过物品共现数据库构建对比学习，使用 InfoNCE 损失（公式1）对齐的表示中引入协同信号。  
  $$ \mathcal{L}_{item} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(\mathbf{z}_i\cdot\mathbf{z}_i^+/\tau)}{\exp(\mathbf{z}_i\cdot\mathbf{z}_i^+/\tau)+\sum_{j=1}^K\exp(\mathbf{z}_i\cdot\mathbf{z}_j^-/\tau)} $$
- **用户表示提取**：将用户属性与交互序列输入第二个 LLM（Qwen3-30B-A3B），用兴趣Token 预测下一物品及类别，微调损失融合相似度与分类交叉熵（公式2）。
- **语义ID 生成**：用残差量化变分自编码器（RQ-VAE）将连续的语义表示离散化为多层语义 ID。量化过程为迭代最邻近搜索（公式3），通过设置高碰撞率使同一语义 ID 对应多个相似实体，自然形成聚类。

### 2.2 语义聚类驱动的特征融合
AKT-Rec 的推荐模型部分包含两个创新模块：

#### （1）聚类引导的自适应嵌入（Cluster-Guided Adaptive Embedding）
- **嵌入分解**：每个用户/物品 ID 被拆分为一个**聚类嵌入** $\mathbf{c}_i$（捕获共享语义）和**个体嵌入** $\mathbf{d}_i$（捕获个性）。
- **非对称知识迁移**：设计不对称的 InfoNCE 目标（公式4），令 $\lambda_1 < \lambda_2$，并配合停止梯度 $sg(\cdot)$，强制知识主要从头部流向尾部。  
  $$ \mathcal{L}_{trans} = \lambda_1 \mathcal{L}_{\text{info}}(\mathbf{c}_i^{head}, sg(\mathbf{c}_i^{tail})) + \lambda_2 \mathcal{L}_{\text{info}}(\mathbf{c}_i^{tail}, sg(\mathbf{c}_i^{head})) $$
- **正交正则化**：通过 $\mathcal{L}_{ortho} = \left(\frac{\mathbf{c}_i^\top \mathbf{d}_i}{\|\mathbf{c}_i\|_2 \|\mathbf{d}_i\|_2}\right)^2$ 鼓励两种嵌入互补，避免信息冗余。
- **活动感知融合**：利用活动特征 $\mathbf{f}_i^{act}$ 经前馈网络 $G_1$ 生成门控权重 $r_i$，动态融合得到最终嵌入：$\mathbf{e}_i = r_i \cdot \mathbf{c}_i + (1-r_i) \cdot \mathbf{d}_i$。

#### （2）层次化特征聚合（Hierarchical Feature Aggregation）
- **实例级特征** $\mathbf{H}_{inst}$：包含用户/物品的个体嵌入、属性、统计特征，并利用目标注意力处理用户行为序列。
- **聚类级特征** $\mathbf{H}_{clust}$：对同一语义聚类内所有用户的实例特征取平均，并基于顶层语义 ID 进行硬检索获取相关行为，再经目标注意力生成序列表示。
- **自适应融合**：使用第二层门控网络 $G_2$，根据用户、物品及其交叉活动特征计算融合权重 $\alpha$，最终输入特征 $\mathbf{f} = \alpha \cdot \mathbf{H}_{clust} + (1-\alpha) \cdot \mathbf{H}_{inst}$，送入排序网络进行CTR预测。

最终损失函数为：$\mathcal{L}_{ctr} = \mathcal{L}_{main} + \mathcal{L}_{trans} + \lambda \mathcal{L}_{ortho}$。
