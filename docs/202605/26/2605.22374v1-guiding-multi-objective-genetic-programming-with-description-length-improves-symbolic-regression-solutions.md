## 摘要
符号回归遗传编程可能会过拟合和结构膨胀，尤其存在噪声时。本文评估描述长度（DL）和分数贝叶斯因子（FBF）准则作为有原则的、数据高效的选择启发式方法的替代方案，用于选择泛化良好的紧凑表达式。我们使用基于费雪信息的参数编码实现DL，并将其与AIC和BIC在多个数据集上进行比较，包括含噪声的合成基准和现实世界的回归问题。我们研究三种搜索/选择策略：（i）以精度和程序长度为目标的多目标搜索，随后进行DL/FBF选择；（ii）直接使用DL作为目标的多目标搜索；（iii）以DL/FBF作为适应度的单目标优化。在数据集上我们发现，与AIC/BIC基线相比，DL/FBF后选择提高了测试性能，并且与DL/FBF中相同的函数复杂度惩罚相结合的BIC产生了类似结果。相反，在单目标GPSR中直接使用DL/FBF作为适应度函数经常导致过早收敛到过于简单的模型。我们总结出在遗传编程工作流中使用DL/FBF作为稳健模型选择工具的实用指导。

## Abstract
Symbolic regression with genetic programming (GPSR) may suffer from overfitting and structural bloat, especially when noise is present. In this paper we evaluate description length (DL) and fractional Bayes factor (FBF) criteria as principled, data-efficient alternatives to heuristics for selecting compact expressions that generalise well. We implement DL using a Fisher-information-based parameter encoding and compare it to AIC and BIC across multiple datasets, including noisy synthetic benchmarks and real-world regression problems. We study three search/selection strategies: (i) multi-objective search for accuracy and program length followed by DL/FBF selection; (ii) multi-objective search using DL directly as an objective; and (iii) single-objective optimisation with DL/FBF as the fitness. Across datasets we find that DL/FBF post-selection improves test performance compared to AIC/BIC baseline and that BIC in combination with the same function complexity penalty from DL/FBF produces similar results. In contrast, using DL/FBF directly as a fitness function in single-objective GPSR frequently induces premature convergence to overly simple models. We conclude with practical guidance for using DL/FBF as robust model-selection tools in genetic programming workflows.

遗传编程符号回归（GPSR）能从数据中自动发现可解释的非线性模型，但在处理含噪声观测时，**极易出现过拟合和模型膨胀（bloat）**，即表达式复杂性无节制增长却未带来相应的精度提升。传统模型选择标准如 AIC 与 BIC 仅通过参数个数处罚复杂度，无法体现表达式的结构复杂性与参数刚性（stiffness），因此在 GPSR 中使用时效果欠佳。

论文核心目标是**验证描述长度（DL）与分数贝叶斯因子（FBF）能否作为更原则性、数据高效的替代方案**，用于在 GPSR 中抑制过拟合与膨胀，并选取泛化性良好的紧凑表达式。作者系统性地研究了 DL/FBF 在不同搜索策略下的作用：**仅用于事后选择，还是直接作为搜索目标或适应度指导进化过程**，旨在为 GPSR 工作流提供明确的工程建议。

### 2. 方法论

论文从最小描述长度（MDL）原理与贝叶斯证据近似两个视角出发，统一了所研究的模型选择准则。

- **统一似然框架**：假设独立同分布高斯误差，未知噪声方差通过残差的 MSE 估计（等同于剖面似然优化），所有准则均基于最大似然估计 $(1)$ 的负对数似然（NLL）计算。
- **对比的模型选择准则**：
    - **AIC**：$\mathrm{AIC} = -2\log\mathcal{L} + 2p$，仅靠参数个数 $p$ 处罚。
    - **BIC**：$\mathrm{BIC} = -2\log\mathcal{L} + p\log m$，$m$ 为观测数，依然只依赖参数计数。
    - **BIC-SR**：在标准 BIC 基础上额外加入函数复杂度项 $2\times\text{func\_comp}$，其中 $\text{func\_comp}=k\log n + \sum_{c_i}\log c_i$，$k$ 为表达式树节点数，$n$ 为不同符号数，$c_i$ 为常量值。
    - **DL（描述长度）**：基于 Fisher 信息矩阵进行参数编码。本文改进在于对 FIM 进行奇异值分解（SVD），在**旋转坐标系**上计算参数复杂度，可更好处理强相关参数。其公式为 $(7)$：
        $$DL = -\log\mathcal{L} + \underbrace{k\log n + \sum_{c_i}\log c_i}_{\text{函数复杂度}} + \frac12\sum_{i=1}^{p}\max\!\bigl(0,\log S_{ii} - \log 3 + \log|\hat{\theta}^{\text{rot}}_i|\bigr)$$
        其中 $S_{ii}$ 为 FIM 的奇异值，体现参数刚性（stiffness）。
    - **FBF（分数贝叶斯因子）**：使用一小部分训练数据（比例 $b=m^{-1/2}$）来校准参数先验，其余用作模型比较，相当于对 DL 进行近似，但不需要不正确的参数离散化先验，公式见 $(8)$。
- **三种搜索/选择策略**：
    1. **MO-Length（多目标+事后选择）**：以 NLL 和表达式长度为两个目标，用 NSGA-II 进行非支配排序。每一代从 Pareto 前沿中，分别依据 AIC、BIC、BIC-SR、DL、FBF 选出一个模型。该策略分离搜索与选择，可直接对比不同准则的选模效果。
    2. **MO-DL（多目标直接优化 DL）**：将第二个目标由长度替换为 DL 中的“函数复杂度+参数复杂度”项，即直接驱动搜索向更小 DL 方向优化。
    3. **SO（单目标适应度）**：分别以 AIC、BIC、BIC-SR、DL、FBF 作为单目标适应度（算法 3），进行标准精英保留遗传编程。
- 所有方法在评估候选解时，均使用 **Levenberg-Marquardt 算法进行参数优化（metic 优化）**，确保参数的局部最优性，以提高 NLL 及模型选择准则的可靠性。

### 6. 主要结论与发现

1. **事后选模效果优异**：在多目标优化（MO-Length）后，使用 DL、FBF 或 BIC-SR 选择最终模型，能获得比 AIC 和标准 BIC 更优越的测试性能，且所选表达式长度显著更短。三种带函数复杂度惩罚的准则效果接近（胜利概率 DL vs. FBF 为 51.7%，vs. BIC-SR 为 51.9%，均在 ROPE 内）。
2. **直接作优化目标需谨慎**：
    - 将 DL 作为多目标的第二项（MO-DL），能进一步降低最终 DL 值（胜利概率 89.1%），但测试误差与 MO-Length+DL 相比**无显著差异**。
    - 将 BIC-SR、DL 或 FBF 直接用作单目标适应度（SO），往往导致**过早收敛到过于简单的欠拟合模型**，测试性能大幅下降（MO-Length+DL 对 SO 各准则的胜利概率在 62%–80%）。
3. **自适应正则化属性**：DL 能根据噪声水平和训练集大小自动调节复杂度偏好：高噪声或小样本时倾向于短表达式，低噪声或大样本时允许更长表达式，无需额外调参，有效抑制了过拟合与膨胀。
4. **计算成本与性能权衡**：BIC-SR 和 FBF 计算成本低于需要完整 FIM 分解的 DL，且选模效果与 DL 相当，因此在工程实践中可作为更高效的选择。

- **系统解耦搜索与选择**：通过 MO-Length 策略创造同一 Pareto 前沿，让不同准则仅事后选模，严格分离了搜索行为和准则本身的选模能力，实验设计严谨。

- **理论与实践的结合分析**：从贝叶斯证据拉普拉斯近似、MDL 原理与 BIC 的近似关系出发，统一解释了 BIC-SR、DL 与 FBF 的共性和差异，并解释了为何加入函数结构复杂性惩罚是关键。

### 8. 不足与局限

- **似然假设单一**：所有实验均基于高斯似然和 i.i.d. 误差假设。对分类问题、非高斯噪声或时间序列依赖关系下，DL/FBF 的行为未做探索。
- **函数复杂度处罚的固定性**：函数复杂度惩罚项 $k\log n + \sum \log c_i$ 虽整体有效，但在个别数据集上调整惩罚强度可能更好，论文未讨论如何自动适应问题特性。
- **缺少与交叉验证等方法的直接对比**：虽提及交叉验证、结构风险最小化、PAC-Bayes 等替代方案，但实验部分未进行实际的运行时与性能对比。
- **参数优化方法的单一性**：所有候选解均采用 Levenberg-Marquardt 拟合参数，未评估其他优化器（如贝叶斯优化、随机搜索）配合 DL 准则时的表现。
- **搜索策略限制**：MO 采用基础的 NSGA-II，未涉及质量多样性（如 MAP-Elites）或更先进的帕累托锦标赛等，可能影响前沿的多样性，但不影响准则间相对评估的核心结论。
