## 摘要
基于文本的序列推荐系统通过融入物品上下文信息显著提升了推荐准确率，但无疑训练成本更高。数据集蒸馏通过将大规模数据集浓缩为一组紧凑的合成样本用于模型训练，提供了一种有前景的解决方案。然而，由于离散物品的庞大词表，将其应用于基于文本的序列推荐并非易事。基于语言模型的物品编码进一步加剧了这一挑战，使得数据集蒸馏中常用的双层优化变得异常昂贵。为此，我们提出了面向文本序列推荐的一阶数据集蒸馏方法（FOSTER），通过三个新颖的组件实现高效且有效的蒸馏：（1）随机物品子集采样，用以替代每个蒸馏步骤中代价高昂的全语料库嵌入提取；（2）基于轨迹锚定参数重置的一阶优化，以避免昂贵的双层梯度计算；（3）明确促进合成序列中语义相似物品共现的正则化。在三个基准数据集上的大量实验表明，FOSTER 始终优于现有的数据集蒸馏和核心集选择基线，仅使用 20 条合成交互序列即可逼近全数据集性能。

## Abstract
Text-based sequential recommender systems, while greatly improving recommendation accuracy by incorporating item contexts, are undeniably more expensive to train. By condensing a large dataset into a compact set of synthetic samples for model training, dataset distillation offers a promising solution. However, its adoption in text-based sequential recommendation is non-trivial given the large pool of discrete items. This challenge is further compounded by language model-based item encoding, which makes bi-level optimization commonly used in dataset distillation prohibitively expensive. To this end, we propose First-order dataset distillation for Text-based Sequential Recommendation (FOSTER), which facilitates effectiveness and efficiency via three novel components: (1) stochastic item subset sampling that replaces costly full-corpus embedding extraction at each distillation step; (2) first-order optimization with trajectory-anchored parameter reset to avoid expensive bi-level gradient computation; and (3) regularization that explicitly promotes co-occurrence between semantically similar items in the synthetic sequences. Extensive experiments on three benchmarks show that FOSTER consistently outperforms existing dataset distillation and coreset selection baselines, approximating full-dataset performance using as few as 20 synthetic interaction sequences.

### 方法论
FOSTER 由三个核心组件构成，分别对应上述三大挑战：
- **组件一：随机物品子集采样（Stochastic Item Subset Sampling, 解决 C1）**
  - 每一步从全量物品集 $\mathcal{V}$ 中均匀采样一个小规模子集 $\mathcal{V}_k$（$|\mathcal{V}_k| = N \ll |\mathcal{V}|$）。
  - 仅基于子集嵌入 $\mathbf{E}_k$ 与 Tucker 分解合成序列概率 $\mathbf{S}_k = [\![ \mathbf{G}; \mathbf{U}, \mathbf{T}, \mathbf{E}_k ]\!]$，大幅降低单步计算量。
  - 此近似同时在内外优化循环中保持一致性。

- **组件二：轨迹锚定的一阶优化（Trajectory-Anchored First-order Optimization, 解决 C2）**
  - 将传统双层优化（式1）等价转换为带约束的单层问题：
    $$\min_{\mathbf{S},\theta} \mathcal{L}_{\text{out}}(\theta,\mathbf{S},\mathcal{D}) \quad \text{s.t.} \quad q(\mathbf{S},\theta) \le 0$$
    其中约束 $q(\mathbf{S},\theta) = \mathcal{L}_{\text{in}}(\mathbf{S},\theta) - \mathcal{L}_{\text{in}}(\mathbf{S},\theta^*(\mathbf{S}))$，仅需一阶梯度求解（Proposition 1）。
  - 使用动态障碍更新（式7）联合优化合成数据 $\mathbf{S}$ 与模型参数 $\theta$，避免通过内层完整轨迹进行反向传播（BPTT）。
  - **参数重置策略**：每 $R$ 步外层循环后，从预记录的真实训练轨迹锚点池 $\mathcal{T}$ 中采样重置 $\theta$，防止 $\theta$ 与 $\mathbf{S}$ 协同劣化导致分布坍塌，同时确保合成数据学习到可迁移的推荐模式。

- **组件三：分布对齐正则化（Regularization for Distributional Hypothesis, 解决 C3）**
  - 强制合成序列满足“分布假设”：语义相似物品的条件分布应趋于一致。
  - 定义语义距离 $d_s(u,v)$（基于预训练模型在交换物品时输出概率差，式8）与条件距离 $d_c(u,v)$（基于合成序列中条件概率差，式9）。
  - 正则化损失 $\mathcal{L}_r = \mathbb{E}_{u,v} [d_s(u,v) - d_c(u,v)]^2$（式10），迫使两种相似度对齐。
  - 最终外层总损失（式11）整合推荐任务损失 $\mathcal{L}_{\mathcal{D}}$、特征匹配损失 $\mathcal{L}_{FM}$ 与 $\mathcal{L}_r$。

### 主要结论与发现
- **性能近似全量**：FOSTER 在 Games/Foods 上仅用 20 条合成序列，Yelp 上用 60 条，**各项指标接近甚至部分超越全量数据训练结果**，并显著优于所有核心集选择与 TD3 基线。
- **效率大幅领先**：通过随机子集采样和一阶优化，FOSTER 将蒸馏时间与显存占用降低一个数量级，使文本序列推荐的蒸馏在消费级 GPU 上可行。
- **组件有效性**：轨迹锚定重置有效防止分布坍塌与参数漂移；共现正则化提升了合成数据的语义保真度；一阶优化+全层训练优于传统 BPTT+末层训练。
- **迁移性良好**：使用 TinyBERT 蒸馏的数据在 Qwen3-4B 上训练，性能大幅超越随机抽样基线，并接近全量数据训练效果，同时训练时间大幅缩短。

### 优点

- **极低样本量**：仅需 20~60 条合成序列即可逼近全量性能，压缩比极高，实用价值显著。
