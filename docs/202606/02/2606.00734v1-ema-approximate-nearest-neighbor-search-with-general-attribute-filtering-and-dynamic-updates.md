## 摘要
带过滤的近似最近邻（FANN）搜索是增强向量数据库查询能力的一项重要新兴任务，支持推荐系统、检索增强生成（RAG）和智能体记忆等应用。然而，现有方法大多局限于范围过滤或标签过滤，其索引构建时间和内存开销往往难以接受。与谓词无关的方法则进一步难以有效应对广泛的谓词选择性范围。本文提出 EMA，一种支持混合数值与类别属性上的多谓词查询以及高效动态更新的过滤型 ANN 算法。EMA 在图的边上附加紧凑摘要 Marker，提供保守的、谓词与几何感知的引导，在 Marker 层级上零假阴性。查询处理时，EMA 通过有界边恢复机制执行 Marker 增强的联合搜索，在保持图导航性的同时实现高效过滤。大量实验表明，EMA 在不同工作负载下相较于现有通用过滤 ANN 方法实现了 1.68 倍至 12.25 倍的加速。

## Abstract
Filtering Approximate Nearest Neighbor (FANN) search is a critical and emerging task for strengthening the query capability of vector databases, supporting applications such as recommendation systems, retrieval-augmented generation (RAG), and agent memory. However, most existing methods are limited to range or label filtering, often incurring unacceptable index construction time and memory overhead. Predicate-agnostic approaches further struggle to handle a wide range of predicate selectivities effectively. In this paper, we propose EMA, a filtering ANN algorithm that supports multi-predicate queries over mixed numerical and categorical attributes, and efficient dynamic updates. EMA introduces Markers as compact summaries attached to graph edges, providing conservative predicate- and geometric-aware guidance with zero false negatives at the Marker level. During query processing, EMA performs Marker-augmented joint search with a bounded edge recovery mechanism, enabling efficient filtering while preserving graph navigability. Extensive experiments demonstrate that EMA achieves 1.68x--12.25x speedup over state-of-the-art general filtering ANN methods across diverse workloads.

# EMA: Approximate Nearest Neighbor Search with General Attribute Filtering and Dynamic Updates

## 1. 论文的核心问题与整体含义

随着向量数据库在推荐系统、检索增强生成（RAG）等应用中的广泛使用，仅依赖向量距离的近似最近邻（ANN）搜索已无法满足实际需求。用户往往需要在语义相似的基础上进一步施加结构化属性的过滤约束，即**过滤型近似最近邻搜索（FANN）**。现有 FANN 方法主要面临四大局限：

- **通用谓词支持不足**：多数方法仅处理范围或标签单一类型，难以同时支持数值、类别及多谓词混合查询。
- **低选择性下鲁棒性差**：当满足谓词的数据占比极小时（例如 1%），图中有效节点稀疏，导致搜索连通性严重下降。
- **离群查询（OCQ）失效**：当满足谓词的点在查询向量局部邻域内稀缺而聚集在远处区域时，现有联合过滤策略难以有效跨区域导航。
- **缺乏动态更新能力**：多数方法基于静态数据设计，面对插入、删除、属性/向量修改等动态场景需全量重建，代价高昂。

本文旨在提出一个统一的 FANN 解决方案，能够在**支持通用多谓词混合过滤（数值+类别）**的同时，保持**对不同选择性（尤其低选择性）的鲁棒性**，并**支持高效动态更新**。

## 2. 论文提出的方法论：EMA

EMA 基于 HNSW 两层图结构，在底部图层边引入**Marker（标记）** 作为核心抽象，实现几何感知的属性摘要，并配套设计了查询时恢复机制与动态维护策略。

### 2.1 核心抽象：Marker 与 Codebook

- **Codebook**：对每个属性（数值或类别）的值域进行离散化，将属性值映射到固定大小的桶（bucket）中。数值属性依据值排序等频分桶，类别属性依类别频率均衡分桶。
- **Marker**：每个边（edge）附带一个紧凑位图，编码该边的主控区域中所有节点的属性桶覆盖信息。对于每个属性，位图中对应桶内若有至少一个节点具有落入该桶的值，则相应位置 1。通过所有属性 Marker 拼接得到每条边的 Marker $ \in \{0,1\}^{s \cdot m} $。

该设计在 Marker 层面保证**零假阴性**，即任何满足查询谓词的节点一定会在被访问边时触发 Marker 匹配（保守近似）；假阳性则被允许，并通过后续精确验证剔除。

### 2.2 索引构建

- **RNG 风格剪枝 + Marker 聚合**：在 HNSW 插入时，对候选邻居进行 RNG 支配判断（若候选 $v$ 已被所选邻居 $w$ 支配，则剪枝边 $(u,v)$）。与传统方法丢弃该边不同，EMA 将被剪枝边的 Marker（对旧边，直接复用已有 Marker；否则实时编码）通过位或（OR）操作**聚合到支配边 $(u,w)$** 的 Marker 上，从而在剪枝后仍然保留被支配区域内节点的属性信息。
- **多样性感知剪枝**：为避免属性信息冗余导致连通性碎片化，EMA 维护一个桶频次计数器，当候选邻居激活的桶中至少有一个桶的频次低于阈值 $M_{div}$ 时，该邻居才被保留（初始 $M/3$ 个邻居无条件保留）。

整体构建时间复杂度为 $O(M \cdot ef_c \cdot n \log n \cdot (M+m))$，与 HNSW 同阶；额外空间开销为 $O(nM \cdot sm)$，仅为常数因子增长。

### 2.3 联合搜索

查询分为两阶段：
- **上层**：纯向量距离导航，快速定位入口点。
- **底层**：**Marker 引导的联合搜索**，并融入**有界边恢复机制**。

**Marker 匹配规则**：对查询谓词生成 Query Marker，在遍历某条边之前，按属性检查：
- 数值属性：边 Marker 属性段与 Query Marker 属性段的位与结果非零，即至少一个桶重叠；
- 类别属性：边 Marker 属性段必须完整包含 Query Marker 的所有置位桶。
只有通过所有属性检查的边才被继续沿行。匹配通过 SIMD 加速。

**边恢复**：当某节点经 Marker 过滤后可选边数低于阈值 $d_{min}$ 时，EMA 将距离最近但 Marker 不匹配的边重新纳入候选，以保证最小出度，维持图连通性。

到达任何节点时，最终使用原始属性值进行精确谓词验证。

### 2.4 谓词聚合与动态支持

EMA 将 Marker 的布尔检查从纯合取推广至通用 AND/OR 表达式，支持复杂组合谓词。

动态更新策略：
- **插入**：天然支持，增量构建 Marker。
- **删除**：惰性删除；当删除比例超过阈值（默认 20%）时触发 **patch** 操作。Patch 利用查询路径记录失效边，并将指向已删节点的边替换为已删节点的最近有效邻居。
- **属性修改**：不变更图连通性，仅反向传播更新受影响边的 Marker（OR 合并）。
- **向量+属性修改**：采用删后插策略，并配合批量 patch。

Patch 操作成本远低于全量重建（论文中 patch 成本仅为全量重建的约 12%）。

### 2.5 理论分析

- **假阳性来源**：Case(1) 剪枝时聚合的支配区域节点属性可能与端点不同；Case(2) 查询谓词粒度小于 Codebook 桶粒度导致过度近似。
- **上界**：Case(1) 假阳性率期望 $\le (1 - sel)(1 - (1-sel)^\mu)$（$\mu$ 为平均支配集大小）；Case(2) 可通过设定足够的 Codebook 大小 $s$，将假阳性控制在目标范围内，给出充分条件 $s \ge \frac{1-FP}{FP \cdot sel} \sum b_j$。$sel$ 较高时 $s$ 可较小；$sel$ 极低时提高 $s$ 可增强剪枝效果。

- **性能显著领先**：EMA 在 label+range 组合查询下，相比最佳基线实现了 1.68× 至 12.25× 的加速（见表 3）；在单一范围、标签及复杂组合谓词下均保持稳定优势。

- **动态更新高效**：插入、删除、属性/向量修改等操作下，EMA 通过惰性删除和 patch 策略维持高 QPS，且维护开销低。

## 7. 优点

- **通用性强**：统一处理数值、类别及复合布尔谓词，摆脱了现有方法对特定谓词类型的依赖。
- **独创的 Marker 设计**：在边级别紧凑编码属性信息，利用 RNG 剪枝过程天然聚合，无额外遍历开销。
- **零假阴性保证**：确保不会因为 Marker 误判而遗漏正确结果，理论可靠。
- **低选择性与 OCQ 下的鲁棒性**：通过边恢复及多样性剪枝显著缓解连通性崩溃问题。
- **理论与实验并重**：不仅提供了构建/查询复杂度分析和假阳性界，还在多个真实数据集上进行了广泛验证。
- **动态更新实用**：轻量级 patch 机制使得 EMA 在流式/动态场景下具有实际部署价值。

## 8. 不足与局限

- **额外存储开销**：每条边附加 Marker，索引体积较 NaviX 等有所增大（例如在 SIFT10M 上为 32GB vs 7.9GB），对内存受限环境可能敏感。
- **部分对比基线受限于系统特性**：Milvus 的内置多线程无法关闭，使得公平比较单线程算法效率有一定干扰。
- **Wiki 数据集上部分基线未完成构建**，可能导致该场景结论的相对优越性需要谨慎对待。
