## 摘要
现代工业推荐系统依赖数千个异构特征——从低维标量（例如统计值）到高维嵌入（例如用户ID嵌入、MLP表示）——以实现高精度预测。鉴于训练相关的巨大计算开销，高效的特征选择至关重要。然而，现有方法面临三个主要瓶颈：(1) 它们通常假设统一特征维度或需要昂贵映射到固定大小；(2) 它们难以处理极端稀疏性，其中大多数特征（如99%+）保持在默认值；(3) 在大规模场景中，传统基于置换的方法计算成本过高。为应对这些挑战，我们提出LeAP（Learnable Adaptive Permutation），一种新颖的、与模型无关的即插即用模块，用于特征选择。LeAP将低效的随机置换过程转化为可学习机制，显著加速特征重要性评估。此外，我们引入了一种针对异构维度和极端稀疏性定制的自适应正则化策略，能在非对称输入空间中实现更优的特征重要性排序。在四个公开推荐数据集上的实验表明，LeAP取得了最先进性能。此外，LeAP已部署于一个大规模工业搜索排序模型，该模型日处理请求超过十亿，模型参数规模达2TB。在此包含12000+总特征维度的真实场景中，LeAP成功识别并移除了超过3600个冗余维度而没有性能下降，这比所比较基线方法的能力高出2到10倍。

## Abstract
Modern industrial recommender systems rely on thousands of heterogeneous features -- ranging from low-dimensional scalars (e.g., statistical value) to high-dimensional embeddings (e.g., user-id embeddings, MLP representations) -- to achieve high-precision predictions. Given the immense computational costs associated with training, efficient feature selection is critical. However, existing methods encounter three primary bottlenecks: (1) they typically assume uniform feature dimensions or require costly mapping to a fixed size; (2) they struggle with extreme sparsity, where the majority of features (e.g., 99%+) remain at default values; and (3) traditional permutation-based approaches are computationally prohibitive in large-scale settings.   To address these challenges, we propose LeAP (Learnable Adaptive Permutation), a novel, model-agnostic plug-in module for feature selection. LeAP transforms the inefficient random permutation process into a learnable mechanism, significantly accelerating the evaluation of feature importance. In addition, we introduce an adaptive regularization strategy tailored for heterogeneous dimensions and extreme sparsity, enabling superior feature importance ranking results across asymmetric input spaces. Experiments on four public recommendation datasets demonstrate that LeAP achieves state-of-the-art performance. Furthermore, LeAP has been deployed in a large-scale industrial search ranking model with over a billion daily requests and a 2TB model parameter scale. In this real-world scenario involving 12,000+ total feature dimensions, LeAP successfully identified and removed over 3,600 redundant dimensions without performance degradation, which is 2 to 10 times the ability of compared baseline methods.

  - **计算效率瓶颈**：传统置换特征重要性方法需要逐个特征打乱并重复前向传播，在数千维特征下计算灾难，无法融入日常迭代。
- **整体含义**：论文提出 **LeAP**（可学习自适应置换），一个模型无关的即插即用模块，将离散、计算昂贵的置换评估转化为端到端可学习机制，并设计自适应正则化以公平处理异构维度与极度稀疏，实现高效、鲁棒的特征选择。

### 2. 论文提出的方法论
- **核心思想**：在单次前向传播中，通过**可学习的门控网络**融合原始特征与批次内打乱后的噪声特征，从而以 $O(1)$ 复杂度评估特征重要性，并利用**置换散度自适应正则化**驱动门控极化，直接输出可用于硬剪枝的特征重要性。
- **关键技术细节**：
  - **可学习置换模块**：
    - 对每个 mini-batch，沿 batch 维度打乱第 $i$ 个特征得到噪声版本 $x'_i$，保留其边缘分布和稀疏模式。
    - 引入可学习门控参数 $\theta_i$，通过温度缩放 Sigmoid 得到门控值 $g_i = \sigma(\theta_i/\tau) \in (0,1)$。
    - 融合特征 $\tilde{x}_i = g_i \cdot x_i + (1-g_i) \cdot \operatorname{sg}(x'_i)$，其中 $\operatorname{sg}$ 表示停止梯度。
  - **自适应正则化（置换散度）**：
    - 计算 batch 内置换散度 $\Delta_i = \frac{1}{B}\sum_{b=1}^{B}\left\|x_i^{(b)} - x_i'^{(b)}\right\|_2$。
    - 利用指数移动平均（EMA）平滑得到稳定统计量 $\bar{\Delta}_i$。
    - 自适应正则化权重 $\lambda_i = \alpha \cdot \bar{\Delta}_i$，总损失 $L_{\text{total}} = L_{\text{task}} + \sum_{i=1}^F \lambda_i \cdot g_i$。
    - **维度自适应**：高维特征置换散度大，自然承受更大惩罚，抵消不公平优势。
    - **稀疏友好**：稀疏特征置换后散度趋近零，惩罚极小，避免误剪枝。
  - **极化保证**：通过总梯度 $\frac{\partial J_{\text{total}}}{\partial g_i} = \frac{\partial J(g_i)}{\partial g_i} + \lambda_i$ 与凸性假设分析，证明有用特征（信号强度 $\Delta J > \lambda_i$）门控会被推向 1，冗余特征推向 0。
  - **部署流程**：即插即用评估 → 基于绝对阈值或比例排序硬剪枝 → 轻量 fine‑tune 上线。

- **自适应正则化设计精巧**：利用置换散度自动对齐维度尺度并容忍稀疏性，从根本上解决异构空间下的评价偏差。

### 8. 不足与局限
- **凸性假设**：理论极化保证基于任务损失凸性假设，而实际深度推荐模型高度非线性，这一假设可能不完全成立，虽实验表明极化有效，但理论边界可能偏理想化。
- **对连续特征与嵌入的公平性**：虽解决了异构维度惩罚，但 1D 连续特征与 256D 嵌入的信息密度不同，仅靠置换散度是否在所有场景下绝对公平，仍需更多理论或实验佐证。
- **依赖在线数据流**：EMA 统计量需在真实数据分布上积累，冷启动或分布剧烈变化时统计可能不稳定，需额外回暖周期。
- **未涉及网络内部特征交互**：LeAP 作用在输入拼接层之后，无法感知高层交叉特征对原始输入的依赖变化，可能保留一些在浅层看似重要但深层被代替的特征。
- **算力披露不足**：缺少对 GPU 型号、内存占用、迭代轮次等具体资源消耗的量化分析，不利于复现或成本估算。
- **公开数据集局限**：所用公开基准的特征维度经过人为统一，未能完全体现最极端的异构性，相关结论的迁移性需谨慎对待。
